# Arkitekturbeslutninger (ADR)

Korte notater om *hvorfor* noe er som det er. Skriv en ny fil når du tar et valg som
en fremtidig utvikler – eller AI-assistent – ellers ville stusset over og "fikset".

Filnavn: `NNNN-kort-tittel.md`, f.eks. `0003-stotte-for-junior-nm.md`.

Mal:

```markdown
# NNNN – Tittel

Status: foreslått | vedtatt | erstattet av NNNN
Dato: ÅÅÅÅ-MM-DD

## Kontekst
Hva var situasjonen og hvilket problem skulle løses?

## Beslutning
Hva ble valgt?

## Konsekvenser
Hva blir lettere, hva blir vanskeligere, hva må vi passe på senere?
```
